# A Way to Look at Agent Architecture
Four Planes and Workflows

By Sooraj Kadnor

This paper looks at AI agent systems as four planes: Intelligence, Orchestration, Tools, and Information. It then defines the workflows that run across those planes, including the kernel workflow, memory, and intelligence call control.

It is written for developers and architects who build production agents. It is a way of looking at agent systems, not a specification.
